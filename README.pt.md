### 🐧 Este é um fork Linux não oficial, mantido pela comunidade

**Flow** é um aplicativo de teleprompter para Windows criado por [LumoRez07](https://github.com/LumoRez07). Este repositório é um **fork** que adiciona uma compilação nativa para Linux (AppImage, `.deb`, `.rpm`, `PKGBUILD` do Arch) sobre o mesmo código-base — **não** é o projeto oficial e **não** é distribuído pela Microsoft Store, SourceForge ou pelos GitHub Releases do original.

O suporte a Linux foi oferecido ao projeto original como um [pull request](https://github.com/LumoRez07/Flow/pull/3); o mantenedor [optou por não aceitá-lo](https://github.com/LumoRez07/Flow/pull/3#issuecomment-5464963891), pois Linux não está no roteiro dele e ele não pode testar/manter isso sozinho, mas autorizou explicitamente que este fork continue existindo sob a licença GPL. Este fork pode ficar atrás do original, e problemas específicos do empacotamento para Linux devem ser reportados no rastreador de problemas **deste** repositório, não no do original.

Esta tradução em português ainda não foi adaptada à nova estrutura focada em Linux. Por enquanto:

- **Para o aplicativo original do Windows** (lista completa de recursos, capturas de tela, downloads oficiais, roteiro): veja **[github.com/LumoRez07/Flow](https://github.com/LumoRez07/Flow)** ou o [README em português](https://github.com/LumoRez07/Flow/blob/main/README.pt.md) dele.
- **Para a documentação completa deste fork Linux** (limitações, primeiros passos, desenvolvimento): veja o [README em inglês](README.md) ou o [README em alemão](README.de.md) deste fork.
- **Para compilar no Linux**: veja [BUILDING-LINUX.md](BUILDING-LINUX.md).

Quer ajudar a traduzir o README deste fork para o português? Pull requests são bem-vindos.

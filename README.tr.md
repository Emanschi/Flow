### 🐧 Bu, topluluk tarafından bakımı yapılan resmi olmayan bir Linux fork'udur

**Flow**, [LumoRez07](https://github.com/LumoRez07) tarafından geliştirilen bir Windows teleprompter uygulamasıdır. Bu depo, aynı koda dayanarak yerel bir Linux derlemesi (AppImage, `.deb`, `.rpm`, Arch `PKGBUILD`) ekleyen bir **fork**'tur — resmi proje **değildir** ve Microsoft Store, SourceForge veya orijinalin GitHub Releases üzerinden **dağıtılmaz**.

Linux desteği orijinal projeye bir [pull request](https://github.com/LumoRez07/Flow/pull/3) olarak sunuldu; bakımcı, Linux yol haritasında olmadığı ve kendisi test/bakım yapamayacağı için [birleştirmemeyi tercih etti](https://github.com/LumoRez07/Flow/pull/3#issuecomment-5464963891), ancak bu fork'un GPL lisansı altında var olmaya devam edebileceğini açıkça belirtti. Bu fork orijinalin gerisinde kalabilir; Linux paketlemesine özgü hatalar orijinalin değil, **bu** deponun sorun izleyicisine bildirilmelidir.

Bu Türkçe çeviri, Linux odaklı yeni yapıya henüz uyarlanmadı. Bu arada:

- **Orijinal Windows uygulaması için** (tam özellik listesi, ekran görüntüleri, resmi indirmeler, yol haritası): **[github.com/LumoRez07/Flow](https://github.com/LumoRez07/Flow)** veya onun [Türkçe README'sine](https://github.com/LumoRez07/Flow/blob/main/README.tr.md) bakın.
- **Bu Linux fork'unun tam belgeleri için** (sınırlamalar, başlarken, geliştirme): bu fork'un [İngilizce README'sine](README.md) veya [Almanca README'sine](README.de.md) bakın.
- **Linux'ta derlemek için**: [BUILDING-LINUX.md](BUILDING-LINUX.md) dosyasına bakın.

Bu fork'un README'sini Türkçeye çevirmeye yardımcı olmak ister misiniz? Pull request'ler memnuniyetle karşılanır.

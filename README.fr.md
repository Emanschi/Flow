### 🐧 Ceci est un fork Linux non officiel, maintenu par la communauté

**Flow** est une application de téléprompteur pour Windows créée par [LumoRez07](https://github.com/LumoRez07). Ce dépôt est un **fork** qui ajoute une compilation native pour Linux (AppImage, `.deb`, `.rpm`, `PKGBUILD` Arch) sur la même base de code — ce **n'est pas** le projet officiel, et il n'est distribué ni via le Microsoft Store, ni SourceForge, ni les GitHub Releases du projet original.

Le support Linux a été proposé au projet original sous forme de [pull request](https://github.com/LumoRez07/Flow/pull/3) ; le mainteneur a [refusé de la fusionner](https://github.com/LumoRez07/Flow/pull/3#issuecomment-5464963891) car Linux n'est pas à sa feuille de route et qu'il ne peut ni le tester ni le maintenir lui-même, mais il a explicitement autorisé ce fork à continuer d'exister sous licence GPL. Ce fork peut donc prendre du retard par rapport à l'original, et les problèmes propres au packaging Linux doivent être signalés dans le suivi des problèmes de **ce** dépôt, pas celui de l'original.

Cette traduction française n'a pas encore été adaptée à la nouvelle structure centrée sur Linux. En attendant :

- **Pour l'application Windows originale** (liste complète des fonctionnalités, captures d'écran, téléchargements officiels, feuille de route) : voir **[github.com/LumoRez07/Flow](https://github.com/LumoRez07/Flow)** ou son [README en français](https://github.com/LumoRez07/Flow/blob/main/README.fr.md).
- **Pour la documentation complète de ce fork Linux** (limitations, prise en main, développement) : voir le [README en anglais](README.md) ou le [README en allemand](README.de.md) de ce fork.
- **Pour compiler sous Linux** : voir [BUILDING-LINUX.md](BUILDING-LINUX.md).

Envie d'aider à traduire le README de ce fork en français ? Les pull requests sont les bienvenues.
